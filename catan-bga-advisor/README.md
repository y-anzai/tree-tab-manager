# Catan Advisor for BGA

Board Game Arena のカタンの盤面を読み取り、ピップ値の表示と、開拓地・盗賊・建設の
評価をサイドパネルに出す Chrome 拡張です（Manifest V3）。

## インストール（開発版）

1. Chrome で `chrome://extensions` を開く
2. 「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で `catan-bga-advisor/` を選ぶ
4. BGA のカタン対局ページを開き、ツールバーのアイコンでサイドパネルを開く

## 機能

- **ピップ値オーバーレイ** — 各ヘクスの数字トークンの上にピップ数（2d6 の組み合わせ数）を
  重ねて表示。オン／オフ、確率(%) 併記、6/8 の強調、盗賊で止まっているヘクスの淡色表示。
- **開拓地候補のランキング** — 建設可能な頂点を、ピップ・資源の多様性・赤数字・盤面全体での
  資源の希少度・港との噛み合い・鉱石＋小麦の都市シナジーで採点して並べる。
- **盗賊の置き場所** — 自分の産出を止めない置き場所のうち、相手の産出停止量を相手の得点で
  重み付けして評価。
- **建設判定** — 手札から今すぐ建てられるもの／不足資源。
- **手動入力** — 自動読み取りが失敗したときに、19 ヘクスの資源と数字を自分で入力できる。

## 設計上の前提と限界

**BGA の DOM 構造は公開仕様ではなく、予告なく変わります。** そのため
`src/content/scraper.js` は特定の id / class を決め打ちせず、`hex` / `tile` / `land` などの
語を含む要素をヒューリスティックに探し、資源はクラス名・背景画像・alt のキーワードから
推定します。読み取れた量（資源 n/19・数字 n/18）と警告は常にサイドパネルに表示するので、
**助言を鵜呑みにする前に読み取り状況を確認してください。** 認識がずれる場合は手動入力に
切り替えられます。

実際の BGA 対局画面で動かして初めて分かる調整点（要素の命名、資源画像のファイル名、
プレイヤーボードの構造）は残っています。セレクタは `scraper.js` 冒頭の
`RESOURCE_KEYWORDS` / `HEX_HINT` / `NUMBER_HINT` / `ROBBER_HINT` に集約してあるので、
実画面を見ながらそこだけ直せば追従できます。

評価値は重み付きヒューリスティックであり、絶対的な正解ではありません。重みは
`src/core/evaluate.js` の `WEIGHTS` にまとめてあります。

対応するのは標準盤（19 ヘクス）のみです。拡張マップや 5〜6 人戦は盤の形が違うため、
ヘクス数の不一致として警告が出ます。

アイコンは同リポジトリの tree-tab-manager から流用した仮のものです。

## 構成

```
src/core/       盤面ロジック（DOM 非依存・Node でもそのまま実行できる）
  pips.js       ピップ数と確率
  geometry.js   19 ヘクスの盤の頂点・辺の導出
  board.js      盤面モデルと産出量の集計
  evaluate.js   開拓地・盗賊・建設の評価
src/content/    BGA ページ側
  scraper.js    DOM からの盤面読み取り
  overlay.js    盤面上のバッジ描画
  main.js       読み取りループとメッセージ処理
src/panel/      サイドパネル UI
src/background.js  service worker（BGA タブでのみパネルを有効化）
```

`src/core/` は DOM に依存しないので、Node からそのまま読み込んで検証できます。

```
node -e "require('./src/core/pips.js');require('./src/core/geometry.js');
         console.log(globalThis.CatanGeometry.buildTopology().vertices.length)"  # => 54
```

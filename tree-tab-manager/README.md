# Tree Tab Manager

Chrome のサイドパネルでタブをツリー形式で管理する拡張機能です。
Manifest V3 / Chrome Side Panel API を使用しています。

## インストール

1. Chrome で `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」から本ディレクトリを選択
4. Chrome ツールバーの拡張機能アイコンをクリックしてサイドパネルを開く

## タブパネル

### ツリー表示モード

タブの親子関係をツリー形式で表示します。

#### 親子関係の構築方法

- **自動**: リンクから新しいタブを開くと、開き元が自動的に親タブになる
- **ドラッグ＆ドロップ**: タブの中央にドロップすると子タブにできる
- **右クリックメニュー**: 「親タブの子にする」「1つ上のツリーの子にする」など

#### 折りたたみ

- タブ名の左にある ▶ をクリックするとサブツリーを折りたたむ
- 折りたたみ中は子孫タブ数がバッジで表示される（青色）
- ツールバーの「すべて折りたたむ」「すべて展開」ボタンで一括操作可能

#### 親タブが閉じられた場合

親タブが削除されると、子タブはその祖父タブの子に自動的に昇格する（リフト機構）

---

### クラウド表示（頻度順）

開いているタブをサイト（URL/タイトル）ごとに集計し、タグクラウド形式で表示します。

- **重み付け**: 過去 90 日間の訪問回数（`visitCount`）に基づき、フォントサイズと背景色（グラデーション）を動的に変更
- **集約**: 同一 URL（フラグメント `#` 以降は除く）かつ同一タイトルのタブを 1 つにまとめ、タブ数をバッジ表示
- **内部ソート**:
  - **表示回数順**: 訪問頻度が高い順に配置
  - **最近利用順**: 最後にそのサイトのタブを開いた時間が新しい順
  - **タブ順**: ウィンドウ内の本来のタブインデックス順
- **操作**: クリックで最初のタブに切り替え。右クリックで「そのサイトのタブを全て閉じる」

---

### 最近利用順モード

タブをツリー構造なしのフラットリストとして、最後にアクティブにした時刻の降順で表示します。

- ツールバーの **「最近利用」** ボタンで切り替え
- アクティブ時刻は `localStorage` に自動保存
- 固定タブセクションは常にツリー表示

---

### タブグループ対応

Chrome のネイティブタブグループ機能と連携します。

#### グループの表示

- ツリー表示モードで、Chromeのタブ順に従いグループと非グループタブを交互に描画
- グループヘッダーに **カラードット・グループ名・タブ数** を表示
- グループ内タブにも小さなカラードットを表示（toggle と favicon の間）
- グループヘッダークリックで展開/折りたたみ

#### グループカラー

| 色名 | 表示色 |
|---|---|
| grey | グレー |
| blue | ブルー |
| red | レッド |
| yellow | イエロー |
| green | グリーン |
| pink | ピンク |
| purple | パープル |
| cyan | シアン |
| orange | オレンジ |

#### グループ操作（右クリック → グループヘッダー）

- **色を変更**: スウォッチ行から 9 色を即時変更
- **グループ名を変更**: prompt で入力
- **グループを解除**: グループ内の全タブをグループから外す

#### グループ操作（右クリック → 非グループタブ）

- **「〇〇」に追加**: 既存のグループ名が一覧表示される（グループ数分の項目）
- **新しいグループを作成**: タブをグループ化し、オプションで名前を設定

#### グループ操作（右クリック → グループ内タブ）

- **グループから除外**: そのタブだけグループから外す

---

### 固定タブセクション

ピン留めされたタブは専用セクションに分離して表示されます。

- セクション上部に「📌 固定タブ (N)」ラベルと件数バッジを表示
- ツールバーの 📌 ボタンでセクション全体の表示/非表示を切り替え
- 固定タブと非固定タブの間のドラッグ＆ドロップは無効
- 固定タブセクション内でも親子関係・ツリー表示は有効

---

### ドラッグ＆ドロップ

タブアイテムをドラッグして並び替えや親子関係を変更できます。

#### ドロップゾーン（タブの高さで 3 分割）

| マウス位置 | 操作 | 表示 |
|---|---|---|
| 上端 25% | そのタブの直上に移動 | 上側に青いライン |
| 中央 50% | そのタブの子タブにする | 背景が青くハイライト |
| 下端 25% | そのタブの直下に移動 | 下側に青いライン |

#### Chrome タブバーとの位置同期

- 上/下ドロップ: Chromeのタブバーの順序も `chrome.tabs.move()` で同期
- 内側（子化）ドロップ: 親タブの直後に Chrome 側でも移動
- グループ境界など制約で `chrome.tabs.move()` が失敗しても、親子関係の変更は保存される

---

### 右クリックメニュー（タブ）

#### 全モード共通

| 項目 | 動作 |
|---|---|
| タブを固定 / 固定を解除 | ピン状態をトグル |
| 子タブとして新しいタブを開く | 右クリックしたタブを親として新規タブを開く ※最近順モードではグレーアウト |
| グループ操作 | （上記「タブグループ操作」参照） |
| 名前を編集 | タブ名をカスタマイズ（URL でも引き継がれる） |
| URL をコピー | クリップボードにコピー |
| タブを閉じる | 単独で閉じる（子タブは閉じない） |

#### ツリーモード専用（最近順モードでは非表示）

| 項目 | 動作 |
|---|---|
| これより下のタブを子タブにする (N個) | Chrome タブバーでこのタブより下の全非固定タブを子化 |
| 子ツリーを1つ上に移動 | 直接の子タブを1つ上の階層に移動（親タブがいる場合のみ） |
| このタブと子ツリーを削除 (N個) | タブとその全子孫を閉じる |
| 親タブの子にする | クリックモードで親タブを選択する |
| 同じドメインのタブをまとめる (N個) | 同ドメインのタブをすべて子化 |
| 1つ上のツリーの子にする | 祖父タブの子として昇格 |

---

### 右クリックメニュー（グループ）

グループヘッダーを右クリックすると表示されます。

| 項目 | 動作 |
|---|---|
| 色選択スウォッチ行 | 9色から選んで即時変更（現在色はアクティブ表示） |
| グループ名を変更 | プロンプトで入力し反映 |
| グループを解除（赤） | グループ内の全タブをグループから外す |

## キーボードショートカット

マウスを使わずにサイドパネルを高速に操作できます。

| キー | 操作内容 |
|:---:|---|
| **T** | タブパネルに切り替え |
| **H** | 履歴パネルに切り替え |
| **F** | お気に入りパネルに切り替え |
| **C** | スニペットパネルに切り替え |
| **S** | 設定パネルに切り替え |
| **/** | 検索ボックスにフォーカス（現在開いているパネルの検索） |
| **M** | 表示モード（ツリー / クラウド / 最近利用など）を順次切り替え |
| **Esc** | 検索ボックスのフォーカスを解除 |

※ 入力フォーム（検索ボックス等）にフォーカスがある間は、`Esc` 以外のショートカットは無効化されます。
※ 設定パネルで、現在有効なショートカットキーの一覧を確認できます。

## セッション管理

### 保存

- セッション名を入力して保存（省略時は現在日時で自動命名）
- 各セッションには URL・タイトル・親子関係・ピン状態・折りたたみ状態を記録
- 最大 20 セッションを保持（古い順に自動削除）
- 保存先: `chrome.storage.local`

### 復元

- 保存済みセッションの一覧から選択
- **新しいウィンドウ**でセッションを復元（現在のウィンドウは変更されない）
- ピン留めタブを先に復元、その後通常タブを順に復元
- 親子関係・折りたたみ状態も復元

### セッション一覧

- 各セッションをホバーすると削除ボタン（🗑）が表示される
- 作成日時と保存タブ数を表示

## 履歴パネル

### 検索・表示
- 過去 30 日間の閲覧履歴を表示（最大 200 件）
- 日付でグループ化（通常表示時）
- 検索ボックス入力でリアルタイムフィルタリング・ハイライト

### スッキリ表示モード（ユニーク・ドメイン集約）
履歴を整理して表示する「スッキリ」モードを搭載しています。

1. **URL ユニーク化**: 同じページの履歴を最新の 1 回分にまとめ、最新のタイトルを維持
2. **ドメイン集約 (ツリー化)**: 同一ドメインへ連続してアクセスしている場合、ドメイン単位のグループとして折りたたみ表示
   - デフォルトで **閉じた状態** で表示され、クリックで展開可能
   - グループには共通のファビコンと含まれる件数を表示
3. **並び順**: 最新のアクセス時間が新しい順にソート

### 操作
- **クリック**: 新しいタブで開く
- **削除ボタン**: その URL の履歴を削除
- **右クリック**: 「ドメインの履歴を全て削除（※実装予定）」など

## ブックマークパネル

### ソートモード（4種類）

| モード | ソート基準 |
|---|---|
| **最近利用** | そのURLを最後に開いた時刻（降順）|
| **最近追加** | ブックマーク追加日時（降順） |
| **頻度順** | 訪問回数（降順） |
| **ツリー** | ブックマークフォルダ構造のまま表示 |

ツリーモードでは各フォルダを展開/折りたたみ可能。

### 検索

- タイトルまたは URL に対して部分一致
- 200ms デバウンス後に再描画

### 操作

- **クリック**: 新しいタブで URL を開く（最近利用時刻が更新される）
- ツリーモード: フォルダ名クリックで展開/折りたたみ

## 設定の永続化

| キー（localStorage） | 内容 |
|---|---|
| `ttm-displayMode` | 表示モード（full / compact / mini） |
| `ttm-tabSortMode` | 並び順モード（tree / recent） |
| `ttm-tab-activation-{tabId}` | タブのアクティブ化時刻（最近順用） |
| `ttm-custom-name-{tabId}` | カスタムタブ名（tabId 紐づけ） |
| `ttm-custom-name-url-{url}` | カスタムタブ名（URL 紐づけ、再訪時に引き継ぎ） |

セッションデータのみ `chrome.storage.local` に保存。
その他の設定は `localStorage` に保存（拡張機能の再起動後も保持）。

## アーキテクチャ

### Background Service Worker（background.js）

- タブの親子関係を `tabParentMap: Map<tabId, parentTabId>` で管理
- タブのメタデータ（折りたたみ状態等）を `tabMetadata: Map<tabId, {collapsed}>` で管理
- Chrome のタブイベントをリッスンし、`notifyPanels()` でサイドパネルに通知
- サイドパネルからのメッセージ（`GET_TAB_PARENTS`, `SET_TAB_PARENT` など）を処理
- セッションの保存・読み込み・復元処理を担当

### サイドパネル（panel.js）

- `state` オブジェクトで全 UI 状態を一元管理
- `loadTabs()` → `renderTabTree()` の流れで表示を更新
- Background との通信は `sendMessage(type, data)` ヘルパー（Promise ラッパー）で行う
- ツリー構築: `buildTabTree()` でフラット配列から親子構造を構築
- グループ描画: `renderNormalTabsWithGroups()` でグループ/非グループを交互にレンダリング

### 主要な状態（state オブジェクト）

```javascript
{
  // タブパネル
  tabs: [],                        // chrome.tabs.Tab の配列（index 昇順）
  tabParents: {},                  // tabId → parentTabId
  tabMetadata: {},                 // tabId → { collapsed }
  collapseState: {},               // tabId → collapsed（UI側ローカル）
  activeTabId: null,               // 現在アクティブなタブ ID
  currentWindowId: null,
  showPinnedTabs: true,            // 固定タブセクションの表示状態
  tabActivationTime: {},           // tabId → 最終アクティブ時刻（ms）
  tabGroupMap: {},                 // tabId → groupId
  tabGroupInfo: {},                // groupId → { id, title, color, collapsed }
  tabGroupCollapseState: {},       // groupId → collapsed（UI側ローカル）
  tabSortMode: 'tree',             // 'tree' | 'recent'
  displayMode: 'full',             // 'full' | 'compact' | 'mini'
  selectingParentFor: null,        // 親選択モード中のタブ ID

  // 履歴パネル
  historyItems: [],
  historyQuery: '',

  // ブックマークパネル
  bookmarkTree: null,
  bookmarkSortMode: 'recent-used', // 'recent-used' | 'recent-added' | 'most-visited' | 'tree'
  bookmarkQuery: '',
  bookmarkFlatList: [],
  bookmarkFolderState: {},         // folderId → collapsed
  recentlyUsedBookmarks: {},       // url → timestamp
  visitCountMap: {},               // url → 訪問回数
  customTabNames: {},              // tabId → カスタム名
  tabCustomNamesByUrl: {},         // url → カスタム名（再訪時引き継ぎ）
}
```

### メッセージ一覧（panel ↔ background）

| メッセージ | 方向 | 内容 |
|---|---|---|
| `GET_TAB_PARENTS` | panel → bg | 親子関係マップを取得 |
| `SET_TAB_PARENT` | panel → bg | 親子関係を設定・削除 |
| `GET_TAB_METADATA` | panel → bg | メタデータを取得 |
| `SET_TAB_COLLAPSED` | panel → bg | 折りたたみ状態を保存 |
| `CLOSE_TAB` | panel → bg | タブを閉じる |
| `ACTIVATE_TAB` | panel → bg | タブをアクティブにする |
| `PIN_TAB` | panel → bg | ピン状態を変更 |
| `NEW_TAB` | panel → bg | 新しいタブを開く |
| `GET_HISTORY` | panel → bg | 履歴を検索 |
| `SAVE_SESSION` | panel → bg | セッションを保存 |
| `LOAD_SESSIONS` | panel → bg | セッション一覧を取得 |
| `RESTORE_SESSION` | panel → bg | セッションを復元 |
| `DELETE_SESSION` | panel → bg | セッションを削除 |
| `TAB_CREATED` | bg → panel | タブが作成された |
| `TAB_UPDATED` | bg → panel | タブが更新された |
| `TAB_REMOVED` | bg → panel | タブが閉じられた |
| `TAB_MOVED` | bg → panel | タブが移動された |
| `TAB_ACTIVATED` | bg → panel | アクティブタブが変わった |
| `TAB_ATTACHED` | bg → panel | タブがウィンドウに附属した |
| `TREE_UPDATED` | bg → panel | ツリー構造が変更された（全体更新） |

## Chrome API 使用一覧

```
chrome.tabs          tabs, tabGroups, windows の操作
chrome.tabGroups     グループの作成・編集・削除・イベント

chrome.action        拡張機能ボタンのクリックイベント
```
